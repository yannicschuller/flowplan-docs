# Tastenkürzel

Alle Kürzel auf einen Blick. Auf Windows und Linux steht <kbd>Strg</kbd> für <kbd>⌘</kbd> und <kbd>Alt</kbd> für <kbd>⌥</kbd>.

| Kürzel | Wirkung |
| --- | --- |
| <kbd>⌘</kbd> <kbd>K</kbd> | Schnellsuche |
| <kbd>⌘</kbd> <kbd>F</kbd> | Auf der Seite suchen: markiert alle Treffer, <kbd>Enter</kbd> bzw. <kbd>⇧</kbd> <kbd>Enter</kbd> springt zum nächsten bzw. vorigen, <kbd>Esc</kbd> schließt. Ausgewählter Text wird zum Suchbegriff. Geht auch in der Desktop-App und den Apps; auf einem Whiteboard sucht es im Board. |
| <kbd>⌘</kbd> <kbd>N</kbd> | Neue Seite |

| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Leertaste</kbd> / <kbd>Strg</kbd> <kbd>Umschalt</kbd> <kbd>Leertaste</kbd> | Desktop-App: Schnell erfassen aus jeder App ([Schnell erfassen (Desktop)](/desktop-capture)) |

| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>X</kbd> | Alle [Abschnitte einklappen](/documents#abschnitte-einklappen) (im offenen Dokument oder Eintrag) |

| <kbd>Esc</kbd> | Dialog, Menü oder Suche schließen |
| <kbd>⌘</kbd> <kbd>Z</kbd> | Löschen, Verschieben oder eine Massenänderung zurücknehmen, solange der Hinweis mit **Rückgängig** sichtbar ist (außerhalb von Textfeldern; im Editor nimmt es die letzte Eingabe zurück) |

Alle Kürzel dieser Tabelle außer <kbd>Esc</kbd> und <kbd>⌘</kbd> <kbd>Z</kbd> lassen sich ändern, siehe [Eigene Tastenkürzel](#eigene-tastenkuerzel).

In der Desktop-App wechselt <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>P</kbd> bzw. <kbd>Strg</kbd> <kbd>Umschalt</kbd> <kbd>P</kbd> zum nächsten [Profil](/offline-and-apps#mehrere-instanzen-profile), sobald mehr als eines gespeichert ist.

## Eigene Tastenkürzel

<kbd>?</kbd> (außerhalb von Textfeldern), <kbd>⌘</kbd> <kbd>/</kbd>, das <kbd>?</kbd> unten in der Seitenleiste oder **Tastenkürzel anzeigen** unter **Einstellungen → Darstellung & Sprache** öffnen die Übersicht. Unter **Überall** hat jede Aktion den Knopf **Ändern**: Danach die neue Kombination drücken – <kbd>Esc</kbd> bricht ab. Die Kombination gilt sofort und für dein Konto auf allen Geräten und Browsern.

- **Konflikte** zeigt die Übersicht an: Gehört die Kombination schon zu einer anderen Aktion, fragt sie nach (**Trotzdem verwenden** nimmt sie der anderen Aktion weg). Kollidiert sie mit einem Kürzel des Editors (etwa <kbd>⌘</kbd> <kbd>B</kbd> für Fett) oder behält der Browser sie meist für sich (etwa <kbd>⌘</kbd> <kbd>W</kbd>), steht ein Hinweis darunter.
- Der Pfeil setzt eine Aktion auf ihre Vorgabe zurück, **×** entfernt ihr Kürzel ganz, **Alle zurücksetzen** stellt alle Vorgaben wieder her. Eigene Kürzel sind mit **Eigene** markiert.
- Kombinationen ohne <kbd>⌘</kbd>, <kbd>Strg</kbd> oder <kbd>⌥</kbd> (wie <kbd>?</kbd>) wirken nur außerhalb von Textfeldern und dem Editor.
- Die Kürzel des Editors, des Seitenbaums, der Präsentation und der geteilten Ansicht sind fest; die Übersicht listet sie zum Nachschlagen.

In der [iPad-App](/offline-and-apps#ipad-fenster-tastatur-und-handoff) mit Hardware-Tastatur listet das iPad die Kürzel mit <kbd>⌘</kbd>, <kbd>⌃</kbd> oder <kbd>⌥</kbd> – auch deine eigenen –, wenn du <kbd>⌘</kbd> hältst.

Die Übersicht zeigt die Tasten so, wie sie auf deinem Gerät heißen: auf dem Mac <kbd>⌘</kbd> und <kbd>⌥</kbd>, sonst <kbd>Ctrl</kbd> und <kbd>Alt</kbd>. Über die API speichert der Befehl `shortcuts.save` dieselben Einstellungen (siehe [API und Webhooks](/api-and-webhooks)).
