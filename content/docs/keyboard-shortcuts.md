# Tastenkürzel

Alle Kürzel auf einen Blick. Auf Windows und Linux steht <kbd>Strg</kbd> für <kbd>⌘</kbd> und <kbd>Alt</kbd> für <kbd>⌥</kbd>.

## Überall

| Kürzel | Wirkung |
| --- | --- |
| <kbd>⌘</kbd> <kbd>K</kbd> | Schnellsuche |
| <kbd>⌘</kbd> <kbd>N</kbd> | Neue Seite |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>N</kbd> | Schnell erfassen (Eintrag in der Datenbank zum Erfassen) |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>E</kbd> | Dokument lesen oder bearbeiten |
| <kbd>Esc</kbd> | Dialog, Menü oder Suche schließen |

## Im Dokument

| Kürzel | Wirkung |
| --- | --- |
| <kbd>/</kbd> | Blockmenü |
| <kbd>@</kbd> | Seite oder Person erwähnen |
| <kbd>⌘</kbd> <kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Fett, kursiv, unterstrichen |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>S</kbd> | Durchgestrichen |
| <kbd>⌘</kbd> <kbd>E</kbd> | Code im Text |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>H</kbd> | Markieren |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>H</kbd> | Verdecken (Spoiler) |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>M</kbd> | Text kommentieren |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>1</kbd>–<kbd>3</kbd> | Überschrift 1–3 |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>8</kbd> / <kbd>7</kbd> / <kbd>9</kbd> | Aufzählung, nummerierte Liste, Aufgabenliste |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>B</kbd> | Zitat |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>C</kbd> | Codeblock |
| <kbd>Tab</kbd> / <kbd>⇧</kbd> <kbd>Tab</kbd> | Einrücken / zurückrücken |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>↑</kbd> / <kbd>↓</kbd> | Block nach oben / unten |
| <kbd>⇧</kbd> <kbd>Enter</kbd> | Zeilenumbruch im selben Block |
| <kbd>⌘</kbd> <kbd>Z</kbd> / <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> | Rückgängig / Wiederholen |
| <kbd>⌘</kbd> <kbd>Enter</kbd> | Kommentar senden; in **Als Markdown bearbeiten**: Übernehmen |
| <kbd>⌘</kbd> <kbd>J</kbd> | [Schreibassistent](/ai#schreibassistent) für Markierung oder Zeile (wenn KI eingeschaltet ist) |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>F</kbd> | Fußnote einfügen (bei ausgewählter Fußnote: bearbeiten) |

Markdown-Kürzel wie `##`, `-`, `[]` oder ` ``` ` stehen unter [Dokumente und Editor](/documents#markdown-kuerzel).

## Whiteboard

| Kürzel | Wirkung |
| --- | --- |
| <kbd>V</kbd> <kbd>H</kbd> <kbd>N</kbd> <kbd>T</kbd> <kbd>R</kbd> <kbd>L</kbd> <kbd>P</kbd> <kbd>X</kbd> <kbd>F</kbd> <kbd>G</kbd> <kbd>C</kbd> | Auswählen, Verschieben, Notizzettel, Text, Form, Linie, Stift, Radierer, Rahmen, Tabelle, Kommentar |
| <kbd>⇧</kbd> <kbd>1</kbd> | Alles anzeigen |
| <kbd>⇧</kbd> <kbd>2</kbd> | Auf die Auswahl zoomen |
| <kbd>⌘</kbd> <kbd>D</kbd> | Duplizieren |
| <kbd>Entf</kbd> | Löschen |
| <kbd>⌘</kbd> <kbd>Z</kbd> / <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Z</kbd> | Rückgängig / Wiederholen |

## Kalender und Timeline

| Kürzel | Wirkung |
| --- | --- |
| <kbd>⌥</kbd> <kbd>↑</kbd> / <kbd>↓</kbd> | Termin um 15 Minuten verschieben (mit <kbd>⇧</kbd>: Ende ändern) |
| <kbd>⌥</kbd> <kbd>←</kbd> / <kbd>→</kbd> | Um einen Tag verschieben |
| <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>←</kbd> / <kbd>→</kbd> | Timeline: Ende ändern |
| <kbd>⌥</kbd> <kbd>Strg</kbd> <kbd>←</kbd> / <kbd>→</kbd> | Timeline: Beginn ändern |

## In dieser Dokumentation

<kbd>/</kbd> springt in die Suche, Pfeiltasten wählen einen Treffer, <kbd>Enter</kbd> öffnet ihn.
