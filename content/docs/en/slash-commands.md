# Block menu commands

Every entry of the `/` block menu – what you type to find it and what it inserts.

At the start of a line or after a space, `/` opens the menu; how to use it is described in [The block menu with /](/documents#the-block-menu-with). Typing on filters by name, shortcut and description, with the best match at the top: instead of the shortcuts in the table, the name works too, in English as in German. With nothing typed, the five blocks you used last come first. Blocks of [block extensions](/plugins) appear under **Extensions** with their own names.

This list is generated from Flowplan's editor. The field above the tables filters it.
