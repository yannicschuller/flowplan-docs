# Keyboard shortcuts

All shortcuts at a glance. On Windows and Linux, <kbd>Ctrl</kbd> stands for <kbd>⌘</kbd> and <kbd>Alt</kbd> for <kbd>⌥</kbd>.

## Everywhere

| Shortcut | Effect |
| --- | --- |
| <kbd>⌘</kbd> <kbd>K</kbd> | Quick search |
| <kbd>⌘</kbd> <kbd>F</kbd> | Find on the page: marks every match, <kbd>Enter</kbd> or <kbd>⇧</kbd> <kbd>Enter</kbd> jumps to the next or previous one, <kbd>Esc</kbd> closes. Selected text becomes the query. Also works in the desktop app and the apps; on a whiteboard it searches the board. |
| <kbd>⌘</kbd> <kbd>N</kbd> | New page |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>N</kbd> | Quick capture (record in the capture database) |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Space</kbd> / <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>Space</kbd> | Desktop app: quick capture from any app ([Quick capture (desktop)](/desktop-capture)) |
| <kbd>?</kbd> or <kbd>⌘</kbd> <kbd>/</kbd> | Keyboard shortcut overview |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>E</kbd> | Read or edit the document |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>B</kbd> | Show or hide the sidebar |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>Z</kbd> | Focus mode on or off |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>K</kbd> | Show or hide comments |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>A</kbd> | Open or close [Ask AI](/ai#ask-your-workspace) (when the panel is open, focus moves into it; from there the shortcut closes it) |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>S</kbd> | Open or close the [split view](/pages-and-spaces#split-view) |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>P</kbd> | [Present](/documents#present) the document |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>Y</kbd> | [Journal](/journal#from-day-to-day): open today (of the journal used last) |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>X</kbd> | [Collapse all sections](/documents#collapsing-sections) (of the open document or record) |
| <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>O</kbd> | Expand all sections |
| <kbd>⌘</kbd> <kbd>[</kbd> or <kbd>⌥</kbd> <kbd>←</kbd> | [Back](/first-steps#back-and-forward) to the page opened before (<kbd>⌥</kbd> <kbd>←</kbd> not while typing – there it moves by words) |
| <kbd>⌘</kbd> <kbd>]</kbd> or <kbd>⌥</kbd> <kbd>→</kbd> | Forward to the next page |
| – | Light or dark theme (no default, your own shortcut possible) |
| <kbd>Esc</kbd> | Close a dialog, menu or the search |
| <kbd>⌘</kbd> <kbd>Z</kbd> | Take back a deletion, a move or a bulk edit while the notice with **Undo** shows (outside text fields; in the editor it undoes the last input) |

Every shortcut in this table except <kbd>Esc</kbd> and <kbd>⌘</kbd> <kbd>Z</kbd> can be changed, see [Your own shortcuts](#your-own-shortcuts).

In the desktop app, <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>P</kbd> or <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>P</kbd> switches to the next [profile](/offline-and-apps#several-instances-profiles) once more than one is saved.

## Your own shortcuts

<kbd>?</kbd> (outside text fields), <kbd>⌘</kbd> <kbd>/</kbd>, the <kbd>?</kbd> at the bottom of the sidebar or **Show keyboard shortcuts** under **Settings → Appearance & language** open the overview. Under **Everywhere**, every action has a **Change** button: press the new combination after it – <kbd>Esc</kbd> cancels. The combination applies at once and for your account on all devices and browsers.

- The overview shows **conflicts**: if the combination already belongs to another action, it asks (**Use it anyway** takes it away from the other action). If it collides with an editor shortcut (such as <kbd>⌘</kbd> <kbd>B</kbd> for bold) or the browser usually keeps it for itself (such as <kbd>⌘</kbd> <kbd>W</kbd>), a note appears below it.
- The arrow resets an action to its default, **×** removes its shortcut altogether, **Reset all** restores every default. Your own shortcuts are marked **Custom**.
- Combinations without <kbd>⌘</kbd>, <kbd>Ctrl</kbd> or <kbd>⌥</kbd> (like <kbd>?</kbd>) only work outside text fields and the editor.
- The shortcuts of the editor, the page tree, presentations and the split view are fixed; the overview lists them for reference.

In the [iPad app](/offline-and-apps#ipad-windows-keyboard-and-handoff) with a hardware keyboard, holding <kbd>⌘</kbd> lists the shortcuts with <kbd>⌘</kbd>, <kbd>⌃</kbd> or <kbd>⌥</kbd> – your own combinations included – in the iPad's overlay.

The overview names the keys as your device does: <kbd>⌘</kbd> and <kbd>⌥</kbd> on a Mac, <kbd>Ctrl</kbd> and <kbd>Alt</kbd> elsewhere. Through the API, the command `shortcuts.save` stores the same settings (see [API and webhooks](/api-and-webhooks)).

## Databases

On the ⋮⋮ handle of a record (table, list, feed, board, gallery, sprints):

| Shortcut | Effect |
| --- | --- |
| <kbd>Space</kbd> | Lift the record; then <kbd>Space</kbd> or <kbd>Enter</kbd> drops it |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move the lifted record up/down one place (sprints: choose the section) |
| <kbd>←</kbd> / <kbd>→</kbd> | Board: move the lifted card to the next column |
| <kbd>Home</kbd> / <kbd>End</kbd> | Move the lifted record to the start/end |
| <kbd>Esc</kbd> | Cancel lifting or dragging; nothing is changed |
| <kbd>⌥</kbd> <kbd>↑</kbd> / <kbd>↓</kbd> | Move the record up/down one place right away |
| <kbd>Enter</kbd> | (not lifted) Open the **Move record** dialog |

## Workflows

On a [workflow's](/workflows) canvas: <kbd>Tab</kbd> between nodes, arrow keys move, <kbd>Enter</kbd> opens the panel, <kbd>A</kbd> appends a node, <kbd>C</kbd> connects, <kbd>Delete</kbd> deletes, <kbd>Ctrl</kbd>+<kbd>D</kbd> duplicates, <kbd>L</kbd> switches to the list, <kbd>F</kbd> fits the view. The overview is under [Workflows → Keyboard](/workflows#keyboard).
