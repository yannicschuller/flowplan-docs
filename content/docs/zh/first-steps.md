# 入门

从第一次登录到创建你的第一个页面：使用 Flowplan 的最初十分钟里要做的事。

## 登录或注册

你可以用电子邮件和密码登录，也可以用通行密钥（指纹、面容或设备 PIN）登录；如果你的组织已经配置好，还可以点击 **使用 SSO 登录**，通过组织的登录系统（OpenID Connect，例如 Keycloak、Authentik、Zitadel 或 Entra ID）登录。登录页面会把你在这台设备上最近一次使用的方式显示为一个大按钮；**使用电子邮件和密码** 会打开登录表单。只要实例允许注册，或者你收到了邀请，就可以用 **创建账户** 注册。之后可以在 **设置 → 账户与安全** 中添加通行密钥。更多内容见 [Sign-in](/sign-in)（英文）。

在一个全新的实例上，你创建的第一个账户就是实例的管理员。如果你在迁移或重新安装，请改为选择 **从备份恢复**（[Restore while setting up](/restore#restore-while-setting-up)）。

第一次登录时，Flowplan 会为你创建一个带有示例页面的私人工作区。使用单点登录（SSO）时，你的姓名、电子邮件地址以及头像（如果有）都来自登录服务提供方。

**语言：** Flowplan 默认跟随浏览器的语言。在 **设置 → 外观与语言 → 语言** 中可以选择德语、英语、英语（美国）、法语或简体中文——选择会在你的所有设备上生效，电子邮件和推送通知也一样。Flowplan 的界面已完整翻译成简体中文；文档目前除本页外都是英文。

## 引导

创建账户后，Flowplan 会带你走一遍最重要的设置：语言和外观、（管理员）实例的设置、（如果需要）从你之前使用的工具迁移、第一批页面、通知，以及在这台设备上离线使用。每一步都可以跳过；之后，侧边栏中的 **入门** 清单会继续帮助你。

从 Notion、AFFiNE、Obsidian、Evernote、Confluence 或 Google Docs 迁移过来？你可以在引导中（**你从哪里来？** 这一步）导入页面，也可以随时在 **设置 → 导入与导出** 中导入。会导入哪些内容、怎样做最好，见 [Moving to Flowplan](/migrate)。

设置页面打开时是一个总览，分为 **个人**、**连接**、**工作区** 和 **帮助与信息** 几组。顶部的搜索框可以帮你找到某个部分。

## 界面

- 左侧 **侧边栏**：切换工作区、搜索、主页、收件箱、你的空间及其页面树，下面是模板、媒体、回收站和设置。
- **主页**：最近编辑的页面、新想法或新项目的快速入口，以及工作区的所有页面——可以用小部件自定义（见下文）。
- 页面的 **页眉**：路径、**分享**、**评论**、收藏，以及 **页面操作** 菜单（`…`）。
- **路径：** 工作区 → 上级页面 → 当前页面。每一级都是链接；你无权阅读的页面不会出现在路径中。

在电脑上，拖动侧边栏的右边缘可以调整宽度，双击边缘可恢复原来的宽度。在手机上，侧边栏会收起：点击左上角的图标或从左边缘向右滑动即可打开。屏幕底部的栏中还有 **主页**、**搜索**、**收件箱**，以及中间用于新建页面的圆形 **+**。iPhone 和 iPad 可以从 App Store 下载应用，Android 也有可下载的应用（[Apps for iPhone, iPad and Android](/mobile-apps)）。

左上角的箭头 **←** 和 **→** 可以回到之前打开的页面或再前进，与浏览器的按钮相同。快捷键：++⌘ [++ 和 ++⌘ ]++（Windows 和 Linux：++Alt ←++ 和 ++Alt →++）。所有快捷键见 [Keyboard shortcuts](/keyboard-shortcuts)。

## 自定义主页

主页属于你自己：点击右上角的 **自定义**（或在快速搜索中输入“自定义主页”），就可以按照你的工作方式用小部件来组织它。手机上所有内容排成一列，平板上两列，大屏幕上三到四列——各个应用和桌面应用显示的是同一个主页。

自定义时：

- **小部件** 打开小部件库：问候、最近的页面、收藏、工作区的页面、我的任务、收件箱、今天的日记、议程、数据库视图、固定页面、快速捕获、专注与计时、习惯、计数器、便笺本、活动、链接等。
- **移动**：拖动手柄、使用上下箭头或键盘。
- **尺寸**：小（一列）、中（两列）、大（三列）或整行宽度。
- **设置**（齿轮）：自己的标题，以及小部件显示的内容。
- **外观**：带颜色、渐变或封面图片的页头、图标、宽松或紧凑的间距。
- **完成** 保存，**取消** 放弃更改。

小部件只显示你本来就有权查看的内容。如果需要一个供多人一起查看的数字和图表页面，请使用 [Dashboard](/dashboards)（仪表板）。

## 你的第一个页面

1. 点击侧边栏中某个空间旁边的 **+**，或在主页上选择 **新页面**。
2. 在顶部输入名称，并在下方选择类型：**文档**、**数据库**、**白板**、**日记**、**仪表板**、**笔记本**、**工作流** 或 **从模板创建**。**空间** 决定页面创建在哪里。
3. 点击 **创建页面**，然后开始写作。所有内容都会自动保存，即使没有网络连接也一样。

在文档中，`/` 会打开块菜单：输入 `/h2`、`/todo` 或 `/table` 并按回车即可插入。编辑器的详细用法见 [Documents and the editor](/documents)。

## 用查找代替翻找

++⌘ K++（Windows 和 Linux：++Ctrl K++）会打开快速搜索，可以搜索标题、正文、数据库记录、评论，甚至上传的 PDF 和 Office 文件的内容。更多内容见 [Search, inbox and push](/search-and-notifications)。

## 帮助与社区

有问题、有想法，或者只是想打个招呼：在 **[Flowplan Discord](https://discord.gg/bCEdB6MPrR)** 上，用户和管理员互相帮助。错误报告和功能请求最好以 [GitHub issue](https://github.com/yannicschuller/flowplan/issues) 的形式提交，这样不会遗漏——尽量用英文。

**设置 → 帮助与信息 → 关于 Flowplan** 会显示正在运行的版本；报告错误时请注明版本。那里的 **新功能** 会打开最新版本的发布说明。
